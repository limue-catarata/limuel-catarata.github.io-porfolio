# Limuel Catarata — CyberCode Personal Portfolio

A futuristic, responsive student portfolio built with plain HTML, CSS, and JavaScript. The design uses a dark interface, neon cyan accents, project cards, responsive navigation, and subtle scroll animations.

## Included files

- `index.html` — portfolio content and sections
- `style.css` — futuristic visual design and mobile responsive rules
- `script.js` — mobile menu, active section navigation, scroll reveal effects, and automatic copyright year
- `README.md` — this guide

## Portfolio sections

- Home and introduction
- About Me
- Skills and interests
- Selected projects:
  - **UpperGround Apparel** — Django e-commerce learning project
  - **LANTERNBOUND: The Last Light** — 2D adventure-puzzle game concept, with a link to the supplied playable game website
  - **Smart Fire Response System** — proposed AI/IoT community safety capstone
- Contact section with a working email draft link

## Preview locally

1. Download and extract the portfolio ZIP.
2. Open the `limuel_portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use a local preview extension.
4. Check the mobile menu by narrowing the browser window.
5. Test the project game link and Email Me button.

No build step or package installation is required for this plain HTML/CSS/JavaScript site.

## Publish with GitHub Pages

1. Create or open your GitHub repository.
2. Upload the **contents** of `limuel_portfolio` to the repository root. Keep `index.html`, `style.css`, `script.js`, and `README.md` together.
3. Open the repository’s **Settings → Pages**.
4. Choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
5. Wait for the deployment status and open the public HTTPS link shown in the Pages settings.
6. Test the public site in a private/incognito browser window and on a phone.

If you use a repository that already contains a website, back up its current files before replacing them.

## Functionality and limitations

- Navigation links scroll to the correct page sections.
- The mobile navigation opens and closes and collapses after a link is selected.
- Navigation highlighting and scroll reveal effects use JavaScript.
- The copyright year updates automatically.
- The contact button opens an email draft.
- The game button opens the external game link in a new tab.
- The project cards describe work and concepts; they do not represent backend integrations unless separately implemented.

## Personalizing the portfolio

- Replace the `LC` photo placeholder in `index.html` with your own image if desired.
- Update your biography and project descriptions to reflect your actual work.
- Add screenshots only for projects you are allowed to share publicly.
- Keep filenames and capitalization consistent for GitHub Pages.

Do not upload passwords, private documents, or secret API keys.
